# VkNewsFeed 
VKNewsFeed is an iOS application for displaying the VK (VKontakte) news feed with dynamically sized cells and a collection view for images in posts. The app uses VK SDK for authentication and data fetching.  

## Stack  
- **iOS Version:** 15.4+  
- **Technologies:** Swift, UIKit, URLSession, AutoLayout  
- **UI:** The interface is created in two ways: through code and through an XIB file. 
- **Libraries:** VK SDK (VKSdkFramework, installed via Carthage)  
- **Architecture:** Clean Swift (VIP)
